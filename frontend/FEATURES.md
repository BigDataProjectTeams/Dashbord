# الميزات الجديدة - نظام مطابقة الفرص

## 1. رفع مستند متطلبات الفرصة

### الوظيفة
- رفع ملف PDF أو TXT يحتوي على متطلبات الفرصة
- إدخال المتطلبات يدوياً عبر نموذج منظم

### المتطلبات المدعومة
- **المهارات المطلوبة**: قائمة مهارات مفصولة بفواصل
- **التخصص المطلوب**: تخصص محدد
- **الحد الأدنى للمعدل التراكمي**: قيمة رقمية من 0 إلى 4
- **المقررات المطلوبة**: قائمة مقررات مفصولة بفواصل
- **الحد الأدنى لبرامج التدريب**: عدد برامج تدريبية
- **الحد الأدنى لساعات الدراسة**: عدد ساعات أسبوعية

### كيفية الاستخدام
1. اضغط على زر "اختيار الملف" لرفع مستند
2. املأ المتطلبات في النموذج (اختياري)
3. اضغط "رفع الملف وإيجاد أفضل المرشحين"
4. سيتم البحث تلقائياً عن أفضل 5 طلاب مطابقة

## 2. عرض أفضل 5 طلاب مطابقة

### المميزات
- **جدول تفصيلي**: يعرض معلومات كاملة عن كل مرشح
- **نسبة المطابقة**: حساب ذكي يعتمد على:
  - المهارات المطابقة (40%)
  - التخصص (20%)
  - المعدل التراكمي (20%)
  - المقررات (10%)
  - برامج التدريب (5%)
  - ساعات الدراسة (5%)

### الرسوم البيانية

#### 1. رسم بياني عمودي (Bar Chart)
- يعرض نسبة المطابقة لكل مرشح
- ألوان مميزة حسب النسبة
- تنسيق أفقي سهل القراءة

#### 2. رسم بياني رادار (Radar Chart)
- مقارنة شاملة بين المرشحين
- عرض مرئي جذاب
- سهولة المقارنة

### معلومات المعروضة
- **الترتيب**: رقم الترتيب مع نجمة للمركز الأول
- **الاسم**: اسم الطالب الكامل
- **البريد الإلكتروني**: للتواصل
- **التخصص**: تخصص الطالب
- **المعدل التراكمي**: مع أيقونة مميزة
- **نسبة المطابقة**: مع لون ووصف (ممتازة/جيدة/متوسطة/ضعيفة)
- **المهارات المطابقة**: المهارات التي يطابقها الطالب
- **أسباب المطابقة**: قائمة بالأسباب التي جعلت الطالب مناسباً

## خوارزمية حساب المطابقة

### الأوزان
1. **المهارات** (40%): عدد المهارات المطابقة / إجمالي المهارات المطلوبة
2. **التخصص** (20%): مطابقة كاملة أو لا شيء
3. **المعدل التراكمي** (20%): نسبة المعدل إلى الحد الأدنى المطلوب
4. **المقررات** (10%): عدد المقررات المطابقة / إجمالي المقررات المطلوبة
5. **برامج التدريب** (5%): مطابقة كاملة أو لا شيء
6. **ساعات الدراسة** (5%): مطابقة كاملة أو لا شيء

### النتيجة النهائية
- مجموع النقاط من 0 إلى 100
- ترتيب تنازلي حسب النسبة
- عرض أفضل 5 فقط

## API Endpoints المطلوبة

### رفع المستند
```
POST /api/opportunities/upload
Content-Type: multipart/form-data
Body: {
  file: File,
  requirements: JSON string
}
```

### البحث عن المطابقات
```
POST /api/opportunities/match
Content-Type: application/json
Body: {
  requirements: {
    requiredSkills?: string[],
    requiredMajor?: string,
    minGPA?: number,
    requiredCourses?: string[],
    minTraining?: number,
    minStudyingHours?: number
  }
}
Response: MatchResult[]
```

## ملاحظات

- الرسوم البيانية تفاعلية ويمكن التكبير والتمرير
